# Prestige Bass Adventures — WordPress theme

Custom black-and-gold block theme for [pba.fish](https://pba.fish) (EasyWP managed WordPress).

## Structure
- `theme.json` — colors, fonts, spacing (Site Editor reads these)
- `templates/`, `parts/` — block templates; header/footer
- `assets/css/main.css`, `assets/js/main.js` — styling and small enhancements
- `inc/booking-form.php` — `[pba_booking_form]` shortcode; requests saved under **Trip Requests** in WP Admin and emailed to *Settings → General → Booking notification email*
- `inc/schema.php` — LocalBusiness JSON-LD on the home page
- `content/home.html` — source of the Home page block content (generated by `tools/build_home.py`, pushed via the REST API)

## Build the install zip
```bash
./tools/package.sh   # writes dist/prestige-bass.zip
```
Upload in WP Admin → Appearance → Themes → Add New → Upload Theme.
